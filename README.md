# Event Ticket Booking Management System

## Project Description
The **Event Ticket Booking Management System** is a SQL-based project developed using MySQL to manage event details, customer information, ticket bookings, and payment records. It helps users maintain booking details, check ticket availability, track booking status, and manage payment information efficiently.

This project demonstrates how SQL can be used to organize data, establish relationships between tables, and automate database operations.

## Technologies Used
- MySQL
- SQL

## Database Tables
The project contains four main tables:

- **Customers:** Stores customer details such as name, email, and phone number.
- **Events:** Stores event information, including event name, date, venue, ticket price, and ticket availability.
- **Bookings:** Stores customer bookings, ticket quantities, booking dates, booking status, and total amounts.
- **Payments:** Stores payment details, including payment method, payment amount, and payment status.

## Key Features
- Manage customer and event information.
- Book tickets for different events.
- Track available tickets and booking status.
- Store and manage payment records.
- Use primary keys and foreign keys to maintain relationships between tables.
- Use JOINs to retrieve data from multiple tables.
- Use aggregate functions, GROUP BY, and HAVING to analyze booking data.
- Create views to simplify data retrieval.
- Use stored procedures to perform booking operations.
- Use triggers to validate ticket availability, restore tickets after cancellation, and validate payment amounts.
- Use transactions and ROLLBACK to understand transaction management.

## Project Objective
The main objective of this project is to develop practical SQL skills by creating a relational database system that manages event ticket bookings and payments. It also helps demonstrate database design, data integrity, automation, and data retrieval skills.
